# 先导结果（2026-11-12，GPU 2）

## Exp 1：C1 在 Ouro 上不成立（方向相反）

Ouro-2.6B，TB(L1, L2)，每格 300 题（两分支格两种行序共 600），答案 0–9 均匀，chance = 0.10。第 4 轮准确率：

| L1 \ L2 | 0（串行链） | 1 | 2 |
|---|---|---|---|
| 1 | 0.91 | 0.46 | |
| 2 | 0.59 | 0.26 | 0.14 |
| 3 | 0.36 | 0.20 | 0.12 |
| 4 | 0.24 | 0.13 | |
| 5 | 0.17 | | |

- **固定 N**：每一格都是串行链（D = N）更好。第 4 轮“两分支 − 串行链”为 N=3 −0.14 [−0.21, −0.07]，N=4 −0.11 [−0.17, −0.04]，N=5 (2,2) −0.10 [−0.16, −0.05]。原假说预测这些差值为正。
- **固定 D**：多加一个并行操作，准确率减半（L1=1 时 0.91 → 0.46）。
- 逐轮 logistic 回归（第 4 轮）：b_D = +0.41 (se 0.06)，b_N = −1.10 (se 0.05)。固定 N 时，链更长反而更好。
- 第 1 轮全部接近 chance（N=2 除外），准确率在第 2–4 轮上升，第 5–8 轮（外推）不再提高。所以 loop 确实在做计算，但能做的只有很浅的程序。
- 稳健性：
  - 只看答案不等于任何字面常数的题，差值仍是 −0.15、−0.14、−0.12，置信区间不含 0。
  - grouped 与 interleaved 行序差别很小（0.23 vs 0.21）。
- Ouro-1.4B（`runs/pilot1`，N ≤ 9）：N ≥ 4 时全部是 chance，结论一致但区分度更低。改小常数、加到 8-shot 都没有改善（`runs/variant_probe*.log`）。

**解读**：在 Ouro 上，难的是“同时持有并合并两个计算出的值”，而不是依赖链的长度。这与“一次 loop 内并行推进多条分支”的说法相反。按原提案的去留规则，C3（按依赖图训练）没有依据。

## Exp 2 / 2b：分支位置替换未找到可靠的独立中间值接口

全量分析见 [Exp 2 表](runs/exp2_2p6b/analysis.md) 与 [Exp 2b 定位表](runs/exp2b_2p6b/analysis.md)。Exp 2 有 400 题 × 3 条等结果路线；未干预的第 4 轮正确率，基底为 49.2%、来源 A 为 46.2%、来源 B 为 44.0%、双来源反事实为 45.3%。在基底及所需来源都答对的条件下，至少有一种有效替换的 `(题, 路线)` 为 467/1,200。以下替换成功率都在各自有效子集上计算，不是全数据集准确率。

- 只替换分支运算行中与基底相同的 token 位置（`line`），或者分支两行中相同的位置（`branch`），在 r=0 时严格没有效果；r=1–3 单次替换后，第 4 轮变成目标反事实答案的比例，单分支最高仅 1.7%，双分支最高 2.3%。持续替换也没有显著改善（单分支最高 2.9%，双分支最高 1.1%）。
- 整个分支两行都替换（包括变化的输入数字，`full`）时，r=0 单分支成功率为 100%，验证了干预代码能改变输入；但它也搬运原始输入，不能证明搬运的是算出的中间结果。r=1 单次替换的 A、B、双分支成功率分别为 90.2%、93.3%、60.2%；r=3 则降到 41.0%、48.1%、31.8%。
- Exp 2b 逐位置替换进一步表明：在 A、B 来源与基底都答对的 53、49 题中，几乎所有与来源相同的 token 单点替换都不能带走目标答案；第 3 轮边界替换最后一个 `Output: ` 位置，A、B 的成功率分别为 26%、10%。这只是单点干预的因果充分性测试，不足以确定信息的唯一存储位置。

**解读**：当前 Ouro 的普通代码提示中，没有发现可以直接从分支自身的相同 token 位置提取、再独立组合的稳定状态。信息可能分布在多个位置，也可能已经在末尾位置混合。与 [提前汇合先导实验](../early_merge/RESULTS.md) 的单末尾状态接口结果合起来看，下一步应先建立受控的通信位置和可靠的晚期汇合阳性对照，而不是直接训练自动分支策略。由于整题前向本身只有约一半正确，这个 patching 实验也不能作为早期汇合能力的最终否定证据。
