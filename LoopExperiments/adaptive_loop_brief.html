研究简报 · 2026-11-12 · Looped Transformer

自适应 Loop 选题简报

目标：让 loop 加深能真正带来提升，并让每个 token 自己决定跑几轮。下面梳理三大会和近期预印本的进展，给出我们建议的论文设计和最先要做的三个实验。

结论

  • 这个方向在 2026 年已经很挤。两个 awesome-list 分别收录了 122 篇和 235 篇论文。三大会里，TaH（ICML'26）、LoopFormer（ICLR'26）、STARS（ICML'26）、Stochastic Stopping（NeurIPS'26）都已经中了。9–10 月又出了 TaH2 和 T-LoopFormer（投 ICLR'27）。单纯再做一个更好的 router 或 halting gate，很难中。
  • 突破口：加深不涨和逐 token 变深其实是同一个问题，应该放进同一套机制里解决。每个 token 的更新幅度有上界并逐轮衰减，停止由一张可证明的证书决定，而不是由 gate 预测。这能直接接上我们已有的 Ouro 有界修正实验。

为什么加 loop 不涨：五种机制

  • 训练深度锚定部分解决

    Ouro 训练时固定 T=4。一篇 135M 小模型预印本（2607.14427）发现，循环模型只用到训练时的平均深度，再加 loop 输出不再变化。我们的 dag_depth 实验里，Ouro-2.6B 跑到第 5–8 轮也不再提高。随机深度训练（Huginn、Stochastic Stopping）能保证多跑不出错，但不会让结果变好。

  • 收敛等于饱和未解决

    收缩映射会停在不动点，多跑几轮没有作用；不收缩又会漂移、崩溃。STARS 明确提出了这个取舍，目前没有人解决。

  • 步长过冲只有分析

    《Right Direction, Wrong Step》（2609.16665）在 Ouro-1.4B/GSM8K 上发现：方向是对的，但一整步走过头了。按二次模型缩短步长，能挽回 94.2% 的失败（teacher-forced，只看当步效果），但没有给出可训练的机制。我们的 clip(z4 − z2, ±B) 就是 logit 空间里的同一件事，这篇必须引用并说清区别。

  • 状态容量未解决

    我们的 dag_depth 实验显示，Ouro 难在同时持有并合并两个值，loop 只能跑很浅的程序。

  • 平均值掩盖了逐 token 的差异待验证

    第 8 轮时只有约 10% 的 token 还在变化（2607.14427）；TaH 也说明少迭代反而更好。我们的推断：多数简单 token 多跑几轮被改坏，少数难 token 在获益，平均起来就是不涨。实验 E1 检验这一点。

逐 token 变深度：现有方法卡在哪

  • 停止没有标签

    各家各用一种信号：TaH 看参考模型是否出错，TaH2 看下一轮的 loss 增益，Ouro 看改善量。2607.20519 和 2607.14427 都发现，直接读收敛或 margin，效果不输学出来的 gate；PonderNet 式的 gate 还会坍缩。

  • 没有真实加速

    TaH 慢约 43%，TaH2 慢 30–34%。2610.32246 指出 batch 的耗时由最慢的 token 决定，halting head 实际上几乎跑满所有迭代。

  • KV 不一致

    提前退出的 token 缺少深层 KV。现有处理是按深度分开缓存再 mask、复制最后一层状态（Ragged KV，2610.09013），或共享 KV。这部分已经很挤，适合拿来当组件，不适合当贡献。

  • 超出训练最大深度就退化

    各家逐 token 的方法都有这个问题。

查新：还没人做的四件事

我们核对了六篇 10–11 月的预印本（2610.32246、2611.02333、2610.14252、2610.09013、2610.06833、2608.18230），以下四件事都没有人做：

  • 把多跑几轮的效果逐 token 拆成变好、变坏、不变三类。
  • 可证明的停止规则。2611.02333 和 2610.32246 都明说自己没有保证。
  • 逐 token 学习步长。
  • 按后续 token 会读取这个 token 的 KV 来决定停止。2610.09013 在附录里用 REINFORCE 试过，没有收益。

推荐的论文设计

主线 · 暂名 LOOP UNTIL CERTAIN

可证明的逐 token 有界步长循环

  1. 发现。在 Ouro 上把跑 1→8 轮的效果逐 token 拆成变好、变坏、不变三类，检验"平均饱和 = 少数难 token 的获益被多数简单 token 的过冲抵消"。
  2. 结构。每个 token、每一轮对 logit（或隐状态）的更新幅度有上界，并按几何级数衰减：
    |Δzt,k| ≤ βt ρtk
    • 第 k 轮之后最多还能改 Rk = βtρtk+1/(1 − ρt)。top-1 与 top-2 的分差 mk > 2Rk 时，无穷多轮之后的 argmax 已经确定。停止判据是一张证书，不需要训练 gate，也不会坍缩。这正是我们 phase-1 的 m2 > 2B 推广到任意轮数。
    • 更新有界，所以多跑永远不会把已经确定的 token 改坏，解决峰值后的崩溃。
    • βt、ρt 由当前状态逐 token 预测。难 token 学到更慢的衰减，获得更长的有效深度。这是绕开 STARS 稳定/有效取舍的关键。
  3. 训练。对难 token 采用长尾深度采样，每一轮都加监督，让模型学会使用超过训练平均值的深度。
  4. 系统。用 Ragged KV 加连续深度 batching 测真实墙钟时间，这是审稿人一定会问的。

需要写明的两点

  • 证书只保证和"有界版本的满深度模型"输出一致，不保证答案正确。真正的代价是被截断的那部分深层修正，也就是 phase-1 测的"深层改判保留率"。
  • 我们的 agentic_loop_depth 实验里，校准阈值换了 few-shot 示例就出现高置信错误（270 个未见程序错 1 个，固定 3 轮全对）。这说明了预测型停止的通病，可以作为证书型停止的动机。

备选 B：按下游价值停止

衡量一个 token 多跑几轮对后面 token 的 loss 有多大影响，而不只看它自己。新颖性最高，风险也最大：如果这个影响和 token 自己的置信度高度相关，这个故事就不成立。实验 E2 先做判断。

备选 C：变深度 on-policy RL

在 RLTT 的基础上，把每个 token 的深度也作为策略的一部分来学。推理引擎需要支持变深度 rollout，工程量很大，暂不推荐。

先做的三个 go/no-go 实验

都在 Ouro-1.4B/2.6B 上做。E1、E2 直接复用我们按轮分开 KV 的 Ouro 前向，各需 1–2 GPU 天。

实验做法继续的条件
E1 逐 token 深度响应 跑 1–8 轮，teacher-forced 下统计每个 token 变好、变坏、不变 第 5–8 轮里变坏的 token 占比明显，且集中在早期高置信的 token 上
E2 下游价值 把第 t 个 token 的第 3–4 轮 KV 换成第 2 轮的，看后续 token 的 Δloss，再和它自身的 Δloss 比较 两者相关性低，且下游影响集中在少数 token 上（例如数字、变量），备选 B 才可行
E3 phase-1 全量 已经写好的 4 轮有界修正实验，约 7 GPU-h；确认 GPU 和阈值后启动 有一段 B 使退出率可观，同时大多数深层改判被保留，主线才可行

时间风险：TaH2 和 T-LoopFormer 已经在审。ICML 2027 通常 1 月底截稿，时间很紧，E1/E2 的结论最好在 12 月中旬前拿到。
