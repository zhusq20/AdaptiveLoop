# 论文实验计划：可证明的逐 token 自适应 loop

2026-11-12 起草。文献调研和选题理由见 [adaptive_loop_brief.html](adaptive_loop_brief.html)。本文只写要做的实验、判定标准和先后顺序。第一阶段（E3）的完整协议仍以 [EXPERIMENT.md](EXPERIMENT.md) 为准。

## 0. 一句话

loop 加深不涨，和逐 token 跑多少轮，是同一个问题。我们的主张：让每个 token、每一轮的更新幅度有上界并逐轮衰减。这样做有三个效果：
- 停止判据变成可证明的证书，不再需要训练一个 gate 去预测；
- 多跑几轮不会把已经确定的 token 改坏；
- 难 token 学到更慢的衰减，从而获得更长的有效深度。

在动手训练之前，先用三个只需推理的实验判断这条路是否成立。

## 1. 要检验的三个假说

| 编号 | 假说 | 对应实验 | 不成立时的后果 |
|---|---|---|---|
| H1 | 平均 loss 随 loop 饱和，是因为少数难 token 的获益被多数简单 token 的过冲抵消 | E1 | 论文的"发现"部分要换，主线结构仍可做，但动机变弱 |
| H2 | 只看 token 自身置信度的停止规则有偏差：有些 token 自己很确定，但它的深层状态对后续 token 很重要 | E2 | 放弃备选 B（按下游价值停止） |
| H3 | 用有界修正换取可证明退出，代价可以接受 | E3 | 固定阈值方案不可行，主线必须靠逐 token 学习的预算 |

## 2. E1：逐 token 深度响应

**目的。** 检验 H1，并在不训练的前提下，初步检验"缩小步长能让外推变安全"。

**设置。**

| 项 | 选择 |
|---|---|
| 模型 | Ouro-1.4B 为主，Ouro-2.6B 复现。版本与 EXPERIMENT.md §1 相同 |
| 轮数 | 1–8 轮。第 1–4 轮在训练深度内，第 5–8 轮是外推 |
| 前向 | 以 `dag_depth/loopmodel.py` 的 `run()` 为基础（无 KV、整段并行、每轮边界可读可改），扩展为读出全部位置 |
| 数据 | GSM8K test 与 MATH-500 的参考解答，用与 phase-1 相同的 chat 提示 teacher-force 参考解答。只统计解答部分的位置。校准/测试划分沿用 phase-1 的 sha256 规则 |
| 读出 | 第 $r$ 轮 $z_r=\mathrm{lm\_head}(h_r)$，FP32，词表均值中心化，与 phase-1 一致 |

**每个位置记录。** 对 $r=1..8$ 记录：参考 token 的 NLL、top-1 与 top-2 分差 $m_r$、argmax 是否等于参考 token。

**分类。** 对轮次对 $(r,r')$，令 $\Delta=\mathrm{NLL}_{r'}-\mathrm{NLL}_r$。$\Delta<-\delta$ 记为变好，$\Delta>\delta$ 记为变坏，其余为不变。主设置 $\delta=0.1$ nats，另报 $0.05$ 与 $0.2$ 作为敏感性检查。同时统计 argmax 翻转：错变对、对变错。

**主要分析。**

1. 平均 NLL 随 $r$ 的曲线，并拆成变好、变坏两部分的贡献。看饱和是"没有变化"，还是"正负抵消"。
2. 第 4→8 轮的变坏比例，按第 2 轮分差 $m_2$ 的十分位分组。过冲假说预测：变坏集中在早期就很有把握的 token 上。
3. 按 token 类型（数字、运算符、变量名、`=`、格式与空白）拆分，看难 token 的尾部由哪些类型组成。

**E1b：阻尼外推（同一批数据）。** 第 5–8 轮改用 $h_{r+1}=h_r+\alpha\,(F(h_r)-h_r)$，其中 $\alpha\in\{1,0.5,0.25\}$，$F$ 是原始一整轮。插值在归一化后的状态上做。是否需要重新归一化，在实现时确定，但 $\alpha=1$ 必须逐位精确复现原模型。观察两件事：变坏能否被压下去；变好的收益能保留多少。

**继续的条件（暂定，跑之前确认）。**

- **支持 H1：** 第 4→8 轮发生变化的 token 中，变坏占比 ≥ 30%；同时，$m_2$ 最高 3 个十分位的变坏率，至少是最低 3 个十分位的 2 倍。
- **支持步长机制：** 存在 $\alpha<1$，使第 5–8 轮的平均 NLL 不高于第 4 轮，同时变好 token 的收益保留 ≥ 70%。
- **不成立：** 变坏占比 < 10%，或变坏与 $m_2$ 无关。

**成本。** 约 1–2 GPU 天，单卡即可。

## 3. E2：token 深度对后续 token 的价值

**目的。** 检验 H2：一个 token 提前退出，对它自己的影响和对后续 token 的影响，是否基本无关。

**设置。** 模型、数据、前向与 E1 相同，固定 4 轮（训练深度）。抽 200 道题，覆盖解答部分的所有位置。

**干预："第 $t$ 个 token 在第 2 轮退出"。** 分两种实现：

- **A. 状态冻结**（先做）：令 $h_3[t]:=h_2[t]$、$h_4[t]:=h_2[t]$，其它位置照常计算。用 `run()` 已有的 `patch` 钩子即可实现。不同的 $t$ 放在 batch 维上并行。
- **B. KV 别名**（在子集上做）：后续 token 在第 3、4 轮注意力里读到的是 $t$ 的第 2 轮 K/V。这与 Ragged KV 等部署方式一致，需要改注意力。

**度量。**

- 自身影响：$\Delta_{\mathrm{self}}(t)$，即位置 $t$ 自己预测下一个 token 的 NLL 变化。
- 下游影响：$\Delta_{\mathrm{down}}(t)=\sum_{s=t+1}^{t+W}\Delta\mathrm{NLL}_s$，$W=64$。另报到序列末尾的总和，以及单个位置的最大值。

**分析。**

1. $\Delta_{\mathrm{down}}$ 分别与 $|\Delta_{\mathrm{self}}|$、$m_2$ 的 Spearman 相关。
2. 集中度：下游影响最大的 10% token，占总下游影响的比例。
3. 在下游影响最大的 10% token 里，有多少会被只看自身置信度的规则判为可退出（$m_2$ 高于 phase-1 校准阈值）。
4. 按 token 类型拆分。

**继续的条件（暂定）。**

- **做备选 B：** Spearman 相关 < 0.3；最大的 10% token 贡献 ≥ 50% 的下游影响；其中 ≥ 30% 会被自身置信度规则判为可退出。
- **放弃备选 B：** Spearman 相关 ≥ 0.6，说明只看自身置信度已经够用。
- 介于两者之间时，先做 B 类干预，再决定。

**成本。** 状态冻结版本按 batch 并行，约 0.5–1 GPU 天。

## 4. E3：phase-1 有界修正全量

协议、指标和自检全部按 [EXPERIMENT.md](EXPERIMENT.md)，判定标准见其 §7（等待确认）。用 `scripts/run_full.sh runs/v1 "<gpus>"` 运行，约 7 GPU-h。

E3 回答的是主线的代价问题：在固定的 $B$ 下，可证明退出率能有多高，被截断的深层改判有多少。如果 §7 判为"不值得继续固定阈值方案"，主线不会因此放弃，而是直接说明为什么预算必须逐 token 学习。

## 5. 三个实验之后

| 阶段 | 条件 | 内容 |
|---|---|---|
| P2 免训练原型 | E1 支持 H1，或 E3 可行 | 在 Ouro 上把两轮有界修正推广到多轮：$\tilde z_k=\tilde z_{k-1}+\operatorname{clip}(z_k-\tilde z_{k-1},\pm\beta\rho^{k})$，取固定的 $\beta,\rho$。先 teacher-forced 统计可证明退出率，再做自由生成，测 GSM8K、MATH-500 准确率与 MBPP+ pass@1 |
| P3 训练 | P2 显示固定预算对难 token 限制过强 | 加一个小头，按当前状态预测 $\beta_t,\rho_t$。对 Ouro-1.4B 做继续训练或 SFT：每轮都加监督，难 token 采用长尾深度采样。另用 135M–400M 的从头训练模型做受控实验 |
| P4 系统 | P3 有效 | Ragged KV 加连续深度 batching，测真实墙钟时间，以及 batch 内最慢 token 对耗时的影响 |

**P3 的对比基线：** Ouro 自带 gate、Huginn 式 KL 收敛退出、按 KL 收敛停止（2607.14427）、TaH/TaH2（如有代码）、STARS、Stochastic Stopping。

**P3 的主要指标：**
- 准确率与平均 loop 数的曲线；
- 第 4–16 轮的外推曲线；
- 难 token 尾部的 loss 是否随深度继续下降；
- 墙钟时间。

## 6. 风险

- **有界会导致饱和。** 收缩意味着最终停在不动点，这正是 STARS 指出的稳定与有效之间的取舍。能否绕开，要看逐 token 学到的预算能否让难 token 继续获益。P3 必须单独报告难 token 尾部的结果。
- **证书的范围有限。** 证书只保证 token 自身的 argmax 与有界模型一致，不保证答案正确；后续 token 读到的 KV 仍会变化。论文里要明确写出保证针对的是哪个模型。
- **加速可能落空。** 25% 的位置从 4 轮降到 2 轮，理想情况下也只省 12.5% 的 loop 计算；batch 的耗时还由最慢的 token 决定。不能把退出率当成加速比。
- **竞争。** TaH2、T-LoopFormer 已经在审。ICML 2027 通常 1 月底截稿，E1–E3 的结论最好在 12 月中旬前拿到。
